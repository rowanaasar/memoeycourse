# 🧠 رحلة تنشيط العقل والذاكرة الخارقة 🚀
### كورس تفاعلي فريد للمذاكرة، حفظ القرآن الكريم، وتنشيط خلايا الدماغ

منصة تعليمية وتفاعلية متكاملة مصممة بأسلوب عصري ومبهج (Clean, Modern & Interactive) لمساعدة الطلاب، حفظة القرآن، والراغبين في تقوية ذاكرتهم ومضاعفة سرعة الحفظ والاسترجاع.

---

## 🌟 ميزات المنصة:
1. **الصفحة الرئيسية (Landing Page):**
   - واجهة مبهجة وعصرية تدعم اللغة العربية بالكامل (RTL).
   - بطاقات استعراض المحاور الأساسية للكورس.
   - قسم المحاضرات الـ 14 (المحاضرة الأولى مفتوحة وتفاعلية، والمحاضرات 2 إلى 14 قادمة قريباً).
2. **صفحة المحاضرة الأولى (مدخل إلى عالم الذاكرة وتنشيط الدماغ 🧠💡):**
   - **بطاقة التعلم السريع:** إبراز محاور المحاضرة في كروت أنيقة.
   - **مفهوم الذاكرة والنسيان:** رسوم توضيحية ومفهوم التخزين والاسترجاع.
   - **أنواع الذاكرة الثلاثة والحواس الخمس:** مستكشف تفاعلي للحواس الخمس (السمع، البصر، الشم، اللمس، التذوق) + اختبار تفاعلي سريع للذاكرة قصيرة المدى.
   - **قدرة الدماغ والنسب العمرية:** إحصائيات معجزة الـ 10 مليون خلية عصبية مع رسم بياني ملون للنسب العمرية وتوضيح حقيقة شيخوخة الدماغ.
   - **غذاء الدماغ 🥗:** الأطعمة والمكملات الطبيعية المنشطة للتشابكات العصبية.
   - **أداة تمرين التنفس العميق 🌬️:** تمرين تفاعلي حقيقي بالأنيميشن (شهيق - حبس - زفير) لتصفية الذهن قبل الحفظ.
   - **لوحة الرسم والتلوين 🎨:** سبورة خربشة تفاعلية لتنشيط الفص الأيمن الإبداعي.
   - **تحدي اختبر فهمك (Quiz) 🏆:** أسئلة تفاعلية فورية مع احتفال Confetti عند اجتياز الاختبار.

## ⚡ المزامنة التلقائية مع GitHub (Auto Git Push):
تم إعداد نظام مزامنة متكامل:
1. **التشغيل التلقائي المستمر:** عند تشغيل ملف `auto_push.bat`، سيراقب أي تعديل في الكود ويقوم بعمل `git add` و `git commit` و `git push` تلقائياً فوراً!
2. **Git Hook التلقائي:** تم تفعيل `post-commit hook` في مستودع المشروع، بحيث أي commit يتم تنفيذه محلياً يتبعه تلقائياً `git push origin main`.
3. **الرفع السريع:** يمكن النقر المزدوج على `push.bat` لرفع كافة التغييرات الحالية في ثانية واحدة.
