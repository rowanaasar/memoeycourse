# 🧠 رحلة تنشيط العقل والذاكرة الخارقة 🚀
### كورس تفاعلي فريد للمذاكرة، حفظ القرآن الكريم، وتنشيط خلايا الدماغ

منصة تعليمية وتفاعلية متكاملة مصممة بأسلوب عصري ومبهج (Clean, Modern & Interactive) لمساعدة الطلاب، حفظة القرآن، والراغبين في تقوية ذاكرتهم ومضاعفة سرعة الحفظ والاسترجاع.

---

## 🌟 ميزات المنصة:
1. **الصفحة الرئيسية (Landing Page):**
   - واجهة مبهجة وعصرية تدعم اللغة العربية بالكامل (RTL).
   - بطاقات استعراض المحاور الأساسية للكورس.
   - قسم المحاضرات الـ 14 (المحاضرات 1 و 2 و 3 مفتوحة وتفاعلية بالكامل، والمحاضرات 4 إلى 14 قادمة قريباً).
2. **صفحة المحاضرة الأولى (مدخل إلى عالم الذاكرة وتنشيط الدماغ 🧠💡):**
   - مفهوم الذاكرة والنسيان والأنواع الثلاثة (الحسية - قصيرة المدى - طويلة المدى).
   - إحصائيات الدماغ (10 مليار خلية عصبية وفصوص المخ) وتفنيد وهم الشيخوخة العقلية.
   - الغذاء الصحي، تحكم الفصين، مؤقت حفظ صفحة القرآن، تمرين تنفس 4-2-8، وتمارين الرسم باليدين والتلوين بلا فراغات.
   - اختبار تفاعلي ختامي (5 أسئلة مع Confetti).
3. **صفحة المحاضرة الثانية (قوانين العقل الباطن ومداخل الشيطان وخطوات الحفظ 🧠✨):**
   - قوانين العقل الباطن (قانون التركيز وقانون التوقع والحديث القدسي الشريف).
   - مداخل الشيطان الخمسة وتفنيد التسويف والعجلة والرياء.
   - خطوات الحفظ قبل النوم (قراءة مرتين بفهم وشرح ذاتي).
   - تمارين كتابة ورسم اليد الشمال واليدين معاً، ونماذج الأشكال الهندسية.
   - اختبار تفاعلي ختامي (5 أسئلة مع Confetti).
4. **صفحة المحاضرة الثالثة (التركيز وعوامل التشتت وتمارين الاسترخاء والحفظ 🎯✨):**
   - عوامل التشتت الخارجية والداخلية ومعدل التركيز.
   - تمارين مضاعفة التركيز (تحدي القراءة بالمعكوس التفاعلي، عد الكلمات بالعينين فقط مع التحقق الفوري، والعد الصامت للأرقام).
   - تكنيك الاسترخاء العميق (مؤقت تنفس تفاعلي 4-2-8 لمدة 5 دقائق مع الوضعية الصحيحة).
   - خطوات الحفظ المتقن وكتابة رؤوس الآيات بالمعكوس باليمين والشمال واليدين معاً.
   - التمارين التراكمية اليومية الستة (الرسم، الكتابة، التنفس، شرب الماء، قراءة النوم، وحفظ الصفحة).
   - اختبار تفاعلي ختامي (5 أسئلة مع Confetti).
