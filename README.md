# 🧠 رحلة تنشيط العقل والذاكرة الخارقة 🚀
### كورس تفاعلي فريد للمذاكرة، حفظ القرآن الكريم، وتنشيط خلايا الدماغ

منصة تعليمية وتفاعلية متكاملة مصممة بأسلوب عصري ومبهج (Clean, Modern & Interactive) لمساعدة الطلاب، حفظة القرآن، والراغبين في تقوية ذاكرتهم ومضاعفة سرعة الحفظ والاسترجاع.

---

## 🌟 ميزات المنصة:
1. **الصفحة الرئيسية (Landing Page):**
   - واجهة مبهجة وعصرية تدعم اللغة العربية بالكامل (RTL).
   - بطاقات استعراض المحاور الأساسية للكورس.
    - قسم المحاضرات الـ 14 (المحاضرات 1 و 2 و 3 و 4 مفتوحة وتفاعلية بالكامل، والمحاضرات 5 إلى 14 قادمة قريباً).
2. **صفحة المحاضرة الأولى (الذاكرة والنسيان، غذاء الدماغ، قدرات الدماغ، تمارين التنفس، الرسم والتلوين 🧠💡):**
   - المحاور الخمسة الأساسية للمحاضرة الأولى.
3. **صفحة المحاضرة الثانية (قوانين العقل الباطن، مداخل الشيطان، خطوات الحفظ الصحيحة، والتمارين 🧠✨):**
   - الأجزاء الأربعة الأساسية للمحاضرة الثانية.
4. **صفحة المحاضرة الثالثة (التركيز وعوامل التشتت، تمارين زيادة، وخطوات الحفظ الصحيحة 🎯✨):**
   - المحاور الثلاثة الأساسية للمحاضرة الثالثة.
5. **صفحة المحاضرة الرابعة (التمارين (اليد والأصابع)، أساسيات الحفظ الصحيح، والرابط الموضوعي 🤲📖✨):**
   - المحاور الثلاثة الأساسية للمحاضرة الرابعة.

---

## 📁 هيكل الملفات:
```
├── index.html        # الصفحة الرئيسية وفهرس المحاضرات الـ 14
├── lecture1.html     # المحاضرة الأولى: الذاكرة والنسيان، غذاء الدماغ، قدرات الدماغ، تمارين التنفس، الرسم والتلوين
├── lecture2.html     # المحاضرة الثانية: قوانين العقل الباطن، مداخل الشيطان، خطوات الحفظ الصحيحة، والتمارين
├── lecture3.html     # المحاضرة الثالثة: التركيز وعوامل التشتت، تمارين زيادة، وخطوات الحفظ الصحيحة
├── lecture4.html     # المحاضرة الرابعة: التمارين (اليد والأصابع)، أساسيات الحفظ الصحيح، والرابط الموضوعي
├── style.css         # التنسيقات الإضافية والأنيميشن
└── README.md         # دليل المشروع والتوثيق
```
